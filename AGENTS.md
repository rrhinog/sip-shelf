# Sip Shelf

Open-source companion app for Owala water bottles (an installable phone web app).

## Agent skills

### Issue tracker

Issues and specs live as GitHub Issues on `rrhinog/sip-shelf`, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default triage roles, unchanged: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the root, created when first needed. See `docs/agents/domain.md`.
